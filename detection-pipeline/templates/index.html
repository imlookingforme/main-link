    🏗️ How It Works

    Phase 1-2: Text

    Claims are matched against official Indian government sources (myScheme.gov.in, PIB) using hybrid retrieval (bge-m3 + BM25) and verified with DeBERTa NLI.

    Phase 3: Media

    Images analyzed for AI generation, OCR + domain checks. Video frames checked for deepfakes via ViT. Audio analyzed for spoofing via Wav2Vec2.

    Phase 4-5: Fusion

    All modality scores fused via calibrated logistic regression: P(fake|s) = σ(w₀ + Σ wₘ·logit(sₘ)). Evidence always provided.
